# Proyecto React + Vite + Material UI (Grid 12 columnas) + PWA

## Instalación y ejecución rápida

1. Descomprime el archivo `.zip`.
2. Abre la carpeta en tu terminal y ejecuta:
   ```bash
   npm install
   npm run dev
   ```
3. Para generar la build lista para desplegar como PWA (por ejemplo en Netlify o Vercel):
   ```bash
   npm run build
   ```
   Sube la carpeta `dist` generada (o conecta el repositorio) y obtendrás tu enlace HTTPS con PWA activa.
